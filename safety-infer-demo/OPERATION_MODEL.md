# 手动输入与运行操作推演

打开 `http://localhost:8000/twin/`。此版本重点完成短时推演与措施选择，无需实时传感器、Neo4j 或大模型密钥。原来的顶升、附着安装和静态工况演示保留在 `/twin/legacy.html`；原图谱和 CNN-LSTM-AT 接口保留。

## 演示流程

1. 默认数据来源为“手动输入（当前数据）”。左侧自由输入回转角、角速度、吊重、幅度、绳长、风速/方向，以及 X/Z 摆角和摆角速度；点击“载入当前输入”或“运行四种操作推演”均使用当前表单，不恢复默认值。固定世界 X/Z 坐标与三维坐标一致，风向表示风力作用方向。
2. 按需输入塔顶两个方向的位移、位移速度，调整设备刚度、主频、阻尼、附着高度与额定能力。无位移观测时采用力学先验；单帧观测只修正位移，不能识别真实刚度、频率或阻尼。
3. 设置不确定范围、障碍物、超限阈值及依据、风险预算、剩余回转角与代价。负角速度时剩余角也须为负。零速度与零剩余角用于停机状态，当前四种候选不包含启动操作。
4. 点击推演。切换四种操作，播放或拖动时间，查看三维摆动、均值轨迹、样本轨迹范围和右侧响应曲线。
5. 查看概率、峰值内力、配对风险变化、估计到达时间、代价分解和不满足的操作约束。满足预算时按总代价排序；不满足时仅显示最低风险候选供复核。
6. 导出输入 JSON（可重导入）、完整结果 JSON 和时间曲线 CSV。使用相同参数、样本数、种子和模型版本复现实验。

推荐演示场景：常规回转（急刹不一定更安全）、前方障碍物（比较减速与制动）、已有摆动、强阵风（可能无措施满足风险预算）、超额定工况（全部措施受约束）。需要示例时在“数据来源”选择具体示例，再点击“填入所选示例”替换表单；示例填入后回到手动模式，可继续修改并推演，不会自动计算。预设仅填充可编辑输入，不内置推荐或固定概率。

## 动力学模型

这是可以核验的低阶研究模型，不是完整有限元模型。固定幅度和绳长，不模拟升降、变幅、双摆吊钩、柔性绳索、碰撞接触、撑杆局部应力或基础失稳。

状态为两向摆角 θ、摆速、塔顶模态位移 q 与位移速度。角速度 ω 与角加速度 α 决定悬点回转加速度：

```
a_pivot = r (-ω² e_radial + α e_tangential)
θ'' = -(g/L) θ - 2 ζ_s sqrt(g/L) θ' + (F_payload/m - a_pivot - q'')/L
q'' = ω_m² (q_equilibrium - q) - 2 ζ_m ω_m q'
T = m g (1 + L |θ'|²/g)
M_lift = T r e_radial
R_payload = T θ
q_equilibrium = M_lift h_free²/(2 EI) + (F_tower + R_payload) h_free³/(3 EI)
M = |M_lift + F_tower H/2 + R_payload H + 2 EI (q-q_equilibrium)/h_free²|
N_attachment = M / (equivalent_lever_arm × attachment_count)
xz_payload = r e_radial + q + L θ
```

计算中统一 SI 单位，力与内力输出转换为 kN、kN·m。风阻采用 `0.613 Cd A v²` N，塔机与吊物迎风面积分别设置。自由段取塔顶至最高附着之间的长度；主模态与等效附着分配仍需设备试验/验算识别。无附着时停用轴力事件，并检查自由高度。

采用 RK4，内部步长 0.02 s，每 0.2 s 输出；超限在全部内部积分点累计，不只在可见曲线点累计。样本合摆角超过 15°时该操作排除出建议，超过约 40°或数值失稳时拒绝整次推演，避免继续解释无效小角度计算。

摆动作为摆模型及通过速度调制改变摆动的物理依据可参考 [NIST 的摆动与起重机操作研究](https://www.nist.gov/publications/crane-operators-tricks-and-other-shenanigans-pendulum)。本项目的塔身耦合项与等效内力转换属于项目研究近似，未声称复现该论文模型或经过其实验验证。

位移观测采用标量高斯更新 `K=σ_prior²/(σ_prior²+σ_measurement²)`，输出观测创新量和后验标准差。没有连续观测时，参数保持用户先验范围，不伪造在线参数识别效果。

## 不确定性与概率

- 初始摆角、摆速、回转角和角速度：中心观测值 ± 用户给出的有界均匀误差。
- 绳长、吊重、EI、主频、阻尼、阻力系数：独立均匀相对误差，每条路径内保持不变。
- 阵风：0.2 s 间隔的相关高斯过程，相关系数 `exp(-0.2/τ)`；限制在 ±3σ并截去负风速。测量偏差及风向误差在路径内固定。
- 所有操作复用相同状态样本、参数样本与世界坐标阵风序列；输出共同样本指纹和随机种子。

风险为 `P(在 [0,H] 内至少一次摆角、塔身弯矩、附着轴力超限，或最小安全净距不足)`，联合事件按同一路径直接计数。**不使用 noisy-OR 合成，也不把图谱关系权重或大模型文字换算为概率。** 默认 H=12 s，256 条路径，可选 4–20 s、64–1024 条路径。

当前就超限的路径对所有操作都计入累计风险。累计曲线不可下降；瞬时曲线可以下降。对每条路径先取全时段最大摆角/内力，再对峰值样本取 P95；这与逐时刻均值的最大值不同。

P05–P95 是逐时刻预测分位范围，不是整条轨迹的同时置信带。Wilson 95%区间只反映有限样本计数误差，零次超限也有非零上界。措施风险变化按共享样本的二元事件差计算，并给出配对标准误近似区间；零差异样本不代表真实风险差已精确确认。区间不覆盖模型形式偏差或未纳入的不确定性。

## 操作与选择规则

回转速度变化采用三次平滑速度曲线 `f(u)=1-(1-f_final)(3u²-2u³)`，u 为时长归一化时间；角位移用解析积分，无方向反转。提前减速后继续以目标比例运行，平缓/立即制动后速度保持零；立即制动也是有限时间急刹，不作无限加速度跳变。

峰值角减速度和加加速度分别为 `1.5 |ω0| (1-f_final)/T` 和 `6 |ω0| (1-f_final)/T²`，使用最大可能初始速度检查操作能力。急刹使用单独的应急能力限值及启用条件。静态吊重、起重力矩、自由高度不满足时不放行任何候选。

先筛选操作约束及模型适用范围，再要求联合超限概率的 **95%计数区间上界** 不超过风险预算，最后最小化：

```
总代价 = 超限概率 × 风险损失权重 + 预计到达时间 × 每秒时间代价 + 停机代价
```

不满足预算时只返回最低上界风险候选和明确提示；无可行候选时不推荐操作。风险降低可为负值，意味着比维持速度更差。风险权重不是事故经济损失的实测值，所有代价使用用户自定义统一单位。

“任务完成时间”当前是到达输入剩余回转角的时间估计，未要求吊物完全消摆或落位。未在预测时段到达时，假设预测结束后恢复原角速度，制动增加重启等待；未模拟后续重新启动。此代价假设在界面及 JSON 中明确输出，不能视为真实作业计划。

## 限值、知识图谱与 AI

各限值均附独立来源字段；默认 6°、3000 kN·m、260 kN 与 2 m 是演示阈值，**不是国家标准统一规定**。真实设备应提供厂家载荷表、塔身验算、附着专项设计和障碍物/电气安全距离要求。

[GB 5144-2006 官方标准信息](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=DD8104E7A4029B7A0AD128D44FC935FB)用于查阅塔式起重机通用安全规程，不能据此推定所有机型统一的摆角和构件内力限值。关于起重机械安全技术规程，另见[市场监管总局 TSG 51—2023 发布公告](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/tzsbs/art/2023/art_99ade7ce1dde4cecb059700a44c169ad.html)。项目未自动实现上述规程的全部要求。

原 Neo4j/CSV 的 CAUSES 关联用于风险链解释。新增 `operation_knowledge.json` 保存四种措施的适用条件、目标风险与代价取舍，作为只读本地知识扩展；实际可行性和风险由计算模块验证。规则不写回 Neo4j。

新的 AI 解释接口只接收原始输入，服务端重新推演后把数值、建议与知识链交给 DeepSeek；客户端不能提交概率字段。大模型不更改推荐，不生成任何数字或百分比；生成带数字的解释会被拒绝，定量结果始终由计算面板显示。默认不调用外部模型，缺密钥/失败时显示错误，不把规则文字伪装成 AI 输出。

修改表单或填入示例后，可直接点击“生成 DeepSeek 解释”。页面先更新当前输入的推演，再生成对应解释；输入错误或推演失败时不会发送模型请求。请求期间修改参数会丢弃过期解释，失败后按钮恢复可点击。密钥配置方式与只读诊断接口见 README 的“按需启用 AI 决策”。

## 实测验证

页面可下载空白 CSV 模板。验证 API 接收 `rows`，每行数字或空值。概率字段为 `risk_probability` 和 `observed_exceedance`（0/1）；两者成对。预测误差字段为 `pred_<quantity>`、`observed_<quantity>`、可选 `p05_<quantity>` 和 `p95_<quantity>`，quantity 包括 `swing_deg`、`mast_moment_kn_m`、`attachment_axial_kn`。

只提供概率记录或只提供响应误差记录都可以。概率记录必须来自独立运行时段，在相同限值、H、联合超限定义下标记结果；重叠滚动窗口或同一运行的相邻时刻不能当成独立概率样本。输出 Brier 分数、十箱 ECE、可靠性曲线及实测频率 Wilson 区间，响应误差输出 MAE、RMSE 和所提供区间的覆盖率。

此功能是**校准程度的核验**，不自动拟合概率映射、不自动识别设备参数。正式校准需要另行划分训练/校准/独立验证数据，识别动力学和扰动范围，再用保留的验证集核验。当前没有实测数据，系统不输出虚构的“准确率”。
